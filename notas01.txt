y resolver problemas , mejoras o tareas especificas en un repositorio.
Facilictan la colaboracion y gestion de proyectos.c
el github el issue es como un chat algo asi y ahi los colaboradores que estan en ese repo
pueden darte consejos y posibles solicuones al issue
Tenemos labels para comentar y labels de asignaciones para
categorizar y asignarse miemnro del equipo.

nueva funcionalidad entonces se crea un issue para eso.
un titulo
una descripcion
requisitos , etc
- luego se le asigna una etiqueta o label a ese issue

del equipo 
este issue generara comentarios y discusiones con sugerencias
preguntas o aportes adicionales

o una relacion entre la tarea y el codigo que se esta asignando.
